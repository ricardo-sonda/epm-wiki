# SmartXCharge (SXC) project

The fictional case project for the EPM group assignment: designing, integrating and delivering an EV fleet-charging management solution for [[lightenergy]], performed by [[advance-energy-systems]] under a €650,000 fixed-price, up-to-32-week turnkey contract ([[smartxcharge-business-case-2026-2027]]). Students plan it **as AES's Supplier Project Manager**.

## Solution in brief

Web portal (managers/operations) + mobile app (drivers); tariff-window and power-cap aware charging plans across four hubs; simple Lisbon battery rules for peak-shaving/load-shifting; finance/asset system integration for automatic cost posting; dashboards for consumption, savings vs baseline, session success, availability, incidents. Integration only — no hardware procurement, no finance-platform redesign.

## Roles (supplier vs client)

| Side | Role | Notes |
|---|---|---|
| Client | Customer Project Sponsor | LightEnergy COO; chairs monthly [[steering-committee]] |
| Client | Client Project Manager | Coordinates client teams, environments, data, approvals |
| Client | Product Owner (Energy & Fleet) | Business priorities, acceptance |
| Client | Client IT/Security Representative | Steering Committee member |
| Supplier | Supplier Executive Sponsor | AES Head/Director of Delivery; oversight, resourcing, escalations |
| Supplier | Supplier Project Manager | AES; day-to-day delivery and control (the students' role) |

In the Delivery 1 Charter, "Sponsor" and "Project Manager" refer to the **supplier** roles; client roles belong in the [[stakeholder-analysis]] ([[delivery-1-instructions]]).

## Life cycle

Annex A5 phases: Initiation & Discovery → Architecture & Integrations → MVP Build → System Testing → UAT / [[lisbon-pilot]] (4 weeks) → Pilot Assessment & Rollout Decision → Hardening & National Rollout → Stabilization & Closure. Control gates: Requirements/Architecture Gate, Lisbon Pilot Authorization, Go/No-Go for National Rollout, Project Closure.
