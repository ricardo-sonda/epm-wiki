# Delivery 3 Instructions

Instructions for the final, consolidated SmartXCharge Project Plan, which must integrate Delivery 1 and 2 feedback and be internally consistent across charter, stakeholders, scope, schedule, resources, costs, communications and risks. Checklist: [[delivery-3-final-project-plan]].

## New required work

- **Communication plan.** Document flows: purpose, owner/sender, recipients, format/channel, timing/frequency, reviewer/approver, storage/versioning. Meetings: purpose, participants, chair/owner, cadence/duration, inputs, outputs, actions, minutes.
- **Risk management plan.** Use the provided "Template Risk Register" workbook for the **5 most significant risks**; rate impact and probability on a **5×5 risk matrix**; derive importance level; plan treatments; if mitigation/contingency adds activities, resources or costs, update the MSP file and the plan. (The workbook itself is not among the ingested files.)

## Minimum plan contents

- Introduction (purpose of the plan) — main document.
- Project Charter — main document. Stakeholder Analysis — annex.
- Scope: introductory text, WBS, WBS dictionary — main document.
- Activities plan: introductory text; High-level plan (client view, milestones-only Gantt as picture) — main; Detailed Gantt / Critical Path — supporting PDF.
- Communication plan: document flows and meetings plan — main.
- Resources & costs: introductory text; Resource Allocations — supporting PDF; Resource Pool (Delivery 2 rates) — main; Costs by Type & Internal Cost Summary (direct labor, other direct costs, 12% overhead, total AES internal cost, **planned margin vs €650,000**) — main.
- Risk register — main.
- Focus on the rubric's PM topics; the RFP's technical deliverables are not required as standalone documents.
